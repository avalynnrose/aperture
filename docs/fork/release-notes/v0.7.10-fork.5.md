# v0.7.10-fork.5

Independently maintained fork of [Aperture](https://github.com/dgruhin-hrizn/aperture) v0.7.10 (upstream commit `99cc9369df`). Not affiliated with the upstream project. Licensed AGPL-3.0; modifications are listed with dates in [NOTICE](https://github.com/avalynnrose/aperture/blob/v0.7.10-fork.5/NOTICE).

**This release changes no features and no defaults.** It makes the fork ready for other people: documentation, installation files, and the AGPL source link inside the application.

## What the fork changes compared with upstream

- **Top Picks Requester**: choose which Seerr user is credited with automatic requests.
- **TV seasons**: request all seasons or season 1 only.
- **Auto-request rules**: strategies (**Top N Eligible** (default), Missing-first = upstream behaviour, Strict Top N, Fill to N), country / TMDB genre / TMDB keyword filters, skip unreleased titles, optional hybrid ranking, per-run cap.
- **Read-only preview** of what the next run would request and why, with a ✕ to skip single titles; confirmation before manual runs.
- Container health check uses `127.0.0.1`.
- Database: migrations `0115` and `0116`, both additive.

New in fork.5: README for the fork, `NOTICE`, `docker-compose.fork.yml` (build from source), `docker-compose.fork-image.example.yml`, upgrade/rollback and release documentation, and a **Source code** link on the sign-in page and in the sidebar.

## Installation (build from source)

```bash
git clone https://github.com/avalynnrose/aperture.git
cd aperture
git checkout v0.7.10-fork.5
cp docker-compose.fork.yml docker-compose.local.yml
# edit APP_BASE_URL, SESSION_SECRET and the three volume paths
docker compose -f docker-compose.local.yml build     # about 4 GB of free RAM
docker compose -f docker-compose.local.yml up -d
```

Then open `http://YOUR_SERVER_IP:3456` and run the setup wizard. Full instructions are in the README.

## Known limitations

- Independently maintained, best effort; no upstream support for the fork's features.
- Requires Seerr with an **admin** API key, and a TMDB API key for the filters.
- The new screens are English only. MDBList lists have no language or release-date data.
- Rolling back is not just starting an older image: older builds would ignore or reject newer rules and request without your filters. Read `docs/fork/upgrading-and-rollback.md` first.
- Published container images (when the package is public) are linux/amd64 only; on other architectures build from source.
- The container image is **not publicly pullable yet**; use the build-from-source steps above.
